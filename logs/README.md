# Event Logs Directory

This directory contains all runtime event logs, terminal outputs, and build traces generated by the Vehicle Monitoring System.

## Log Files

- `vehicle_events.log` - Main core event log containing startup operations, thread initializations, and system warnings with timestamps.
- `dtc_history.log` - Diagnostic Trouble Codes history, explicitly storing the snapshot bounds for every active DTC fault.
- `performance_metrics.log` - Periodic system performance snapshots indicating average vehicle speed, peak temperatures, and most frequent alerts.
- `terminal_output.log` - A 1:1 replica of the Live Dashboard UI that is printed to the terminal console during execution.
- `build.log` - Detailed compilation, linking, and CTest execution logs generated directly by `run.bat`.
- `test_results_<TIMESTAMP>.log` - The automated testing summaries generated when running the full test suite in `testcases/run_all_tests.bat`.
